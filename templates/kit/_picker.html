{# dashboard-kit — filesystem picker dialogs (folderPicker / filesPicker). A project-tree browse dialog on the browser top layer (native , via the kit `modal` macro). The kit owns the CHROME: the correctly-titled modal + the browse scaffold (breadcrumbs, listbox, empty note, Cancel/Select actions) styled by `.kit-picker*` in kit.css. The APP owns the DATA: it points `browse_url` at an endpoint that returns a directory listing and supplies a small driver that loads listings, tracks selection, and does something with the picked paths (e.g. the DEVPROTOCOL `reference_browse.js` clones them into a reference list). Two macros, one per mode, so each dialog has a FIXED, correct title — no shared-modal mistitling. `data-picker-mode` on the body tells the app driver whether files are selectable (file mode) or the current folder is the pick (folder mode). The inner controls carry NO `name=` — they are pure JS state, never part of a form POST.
