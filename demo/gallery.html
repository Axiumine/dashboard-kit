🗂️ Layout shells

page.html.containerlayout · max 1180

Standard contained page — a centred column (max-width 1180) holding header + content. The wrapper this whole gallery sits in. Extend it for data-dense pages (roster, config editor).

focused.html.container--narrowlayout · max 760

Narrow single-task column (max-width 760) for a create form, a delete confirm, one focused action. Same slots as page.html — swap the one {% extends %} line to move between them.

base.htmllayout · shell

The <!doctype> shell every page extends — owns <head>, theme stylesheet links, htmx + kit.js, the body / scripts_foot slots. You never extend this directly; extend page.html or focused.html.
